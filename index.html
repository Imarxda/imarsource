Configuración Supabase

Solo se guarda en esta sesión, nunca en el código.
Ver estructura de tablas necesaria en Supabase 
modelos
  id            uuid / int8 (PK)
  nombre        text
  codigo        text
  descripcion   text
  foto_perfil_embed  text   -- link directo o embed de la foto de perfil
  instagram_url text   -- link a Instagram del modelo. Columna nueva, agregarla si no existe.
  likes_mes     int8  (default 0)
  creado_en     timestamptz

fotos
  id            uuid / int8 (PK)
  modelo_id     -> referencia a modelos.id
  embed_code    text   -- link directo o embed de cada foto de la galería
  creado_en     timestamptz

eventos
  id            uuid / int8 (PK)
  titulo        text
  fecha_evento  date
  banner_url    text
  descripcion   text
  interesados   int8 (default 0)  -- contador de "Me interesa". Columna nueva, agregarla si no existe.

portada
  id            int8 (usar siempre el valor 1, fila única)
  imagen_url    text   -- link directo a la imagen de portada
  titular       text
  subtitulo     text
  header_bg_url text   -- link directo a la imagen de fondo del header (logo). Columna nueva, agregarla si no existe.
  layout        jsonb  -- posición/tamaño/color de logo, titular, líneas secundarias, bajadas, personaje y marca de agua.
                        -- Se edita desde admin.html (Editar Portada), no desde este panel viejo.
Modelos
Cada modelo tiene un único perfil, como una cuenta de Instagram: se crea una sola vez y después se le van sumando fotos a su galería personal.
Podés pegar el link directo de la imagen, o cualquier embed: una etiqueta <img>, un iframe de ImgBB, Cloudinary, etc.
Esta foto se suma a la galería del perfil seleccionado.
Fotos de este modelo
Seleccioná un modelo para ver su galería.
Eliminar un perfil borra también todas las fotos de su galería. Esta acción no se puede deshacer.
Todavía no hay modelos creados.
Portada de la Temporada
Esta es la imagen y el titular grande que aparecen al inicio del sitio. Actualizala cada mes o cada temporada.
Subí la foto a ImgBB, Cloudinary u otro hosting gratuito y pegá aquí el link directo a la imagen. Se recomienda una foto vertical u orientación retrato para que luzca bien en celulares.
Fondo del Header (logo)
Imagen que aparece detrás del logo, arriba de todo el sitio. Cambiala cuando quieras sin tocar el logo.
Subí la imagen a ImgBB, Cloudinary u otro hosting gratuito y pegá aquí el link directo. Dejalo vacío para que el header quede sin imagen de fondo.
Nuevo Evento
Completá los datos para agregar el evento al carrusel y al ticker.
Subí la imagen a ImgBB, Cloudinary u otro hosting gratuito y pegá el enlace directo.
